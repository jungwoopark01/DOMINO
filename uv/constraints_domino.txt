# Version floor/ceiling for the DOMINO venv (./.venv). Pass to every `uv pip install`
# that is not `-r script/requirements.txt`.

# Why this file exists: envs/curobo/setup.cfg:50 declares an UNPINNED
# `torch>=1.10`. Installing curobo without --no-deps resolved torch to 2.13.0

# extensions with -std=c++20 -- breaking curobo's own helper_math.h `lerp`
# against C++20's std::lerp. It also dragged numpy, scipy, trimesh and
# setuptools forward with it.
